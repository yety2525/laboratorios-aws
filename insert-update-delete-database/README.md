# Laboratorio AWS: Insert, Update, and Delete Data in a Database

## Descripción
Laboratorio práctico para aprender a insertar, actualizar y eliminar datos utilizando SQL en una base de datos MariaDB dentro de un entorno AWS Academy.

## Objetivos
- Conectarse a una instancia EC2 mediante Session Manager.
- Consultar bases de datos y tablas.
- Insertar registros con `INSERT`.
- Actualizar información con `UPDATE`.
- Eliminar registros con `DELETE`.
- Restaurar los datos originales desde una copia de seguridad.

## Servicios y herramientas
- Amazon EC2
- AWS Systems Manager Session Manager
- MariaDB
- SQL
- Linux
